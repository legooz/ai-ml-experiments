# Text Classification

Newsgroups compares Bernoulli and multinomial naive Bayes and fetches the public 20 Newsgroups dataset. Its sample display indexes the unsplit data rather than the test split, so displayed text can mismatch predictions; converting the entire test matrix to dense is also unnecessary. Reuters uses Keras dataset loaders and compares SimpleRNN/LSTM models. Outputs and downloaded text are not stored in this repository; no quantitative performance claim is made.

Only Python syntax was checked during portfolio preparation. See the repository [provenance](../PROVENANCE.json).
