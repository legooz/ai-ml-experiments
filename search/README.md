# Search

The maze notebook compares A-star with heuristic-only greedy best-first search on a custom maze. The historical cells use the same astar function name, so later cells overwrite it. Reconstructed paths are returned in reverse order without the start node. These are visual search experiments, not a tested shortest-path library. Requires NumPy and matplotlib.

Only Python syntax was checked during portfolio preparation. See the repository [provenance](../PROVENANCE.json).
