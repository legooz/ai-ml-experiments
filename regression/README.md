# Regression

Manual single-feature gradient descent and a two-feature version use synthetic arrays. The diabetes notebook uses scikit-learn's bundled dataset. The generalized-feature draft had shape/indexing errors and is omitted; only its two-feature cells were selected. Requires NumPy, pandas, SciPy, matplotlib, and scikit-learn. No original outputs or benchmark claims are retained.

Only Python syntax was checked during portfolio preparation. See the repository [provenance](../PROVENANCE.json).
