# Classification

Nearest-neighbor decision regions, a heart-disease decision tree, wine ensembles, synthetic nonlinear MLP, and MNIST naive Bayes. MNIST and the heart-disease exercise fetch public datasets. The heart-disease labels/evaluation need review and the exercise is not a clinical model. Graphviz Python bindings and a Graphviz installation are needed for tree rendering; ensembles use XGBoost. These are course exercises with scaffold attribution, not independently validated models.

Only Python syntax was checked during portfolio preparation. See the repository [provenance](../PROVENANCE.json).
