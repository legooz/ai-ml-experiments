# Neural Networks

CIFAR-10 uses the Keras dataset loader. Power-plant regression downloads the UCI CCPP archive and trains a dense model. Bike-sharing regression expects UCI Bike Sharing hour.csv beside the notebook; data is not redistributed. Both regression notebooks fit scaling statistics before the train/test split, causing data leakage; fix preprocessing before treating results as estimates of generalization. Hyperparameter comments are historical observations, not reproduced results. TensorFlow/Keras compatibility and model training have not been checked.

Only Python syntax was checked during portfolio preparation. See the repository [provenance](../PROVENANCE.json).
